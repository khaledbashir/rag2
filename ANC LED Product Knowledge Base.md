# ANC LED Product Specifications — Knowledge Base

> This document contains complete technical specifications for every LED display product ANC uses. Use this as the source of truth when filling out Product Data Forms, spec sheets, RFP responses, or any document requiring manufacturer specifications.

---

## How to Use This KB

When you need specs for a display:
1. Find the **Vendor** and **Model** from the cost analysis or LED Cost Sheet
2. Search this document for that model
3. All 37 Product Data Form fields are covered per product
4. For power/weight calculations, use the per-cabinet specs and multiply by cabinet count

**Cabinet Count Formula:**
```
Display Area (sq ft) × 0.0929 = Area (m²)
Cabinet Area = (width mm × height mm) / 1,000,000 = Area (m²)
Cabinet Count = ROUNDUP(Display Area m² / Cabinet Area m²)
```

**Power Calculations:**
```
Power at 0% (black) = Max watts per cabinet × 0.15 × cabinet count ÷ 1000 = KW
Power Avg (typical) = Avg watts per cabinet × cabinet count ÷ 1000 = KW
Power at 100% (white) = Max watts per cabinet × cabinet count ÷ 1000 = KW
BTU = KW × 3412
```

**Weight Calculation:**
```
Total Weight = Weight per cabinet (lbs) × cabinet count
```
